# Гуси-Лебеди

Сайт творческой мастерской и керамических дней рождения.

[gusilebedy.ru](https://gusilebedy.ru/)

## Заявки с сайта

Внизу страницы — блок «04 / Заявка». Человек заполняет имя, телефон, формат,
дату и количество гостей, и заявка **приходит сообщением в Telegram** — телефон
звякнул, вы перезвонили. Дублировать её на почту не обязательно, но можно.

Как выглядит сообщение в Telegram:

```
🎉 Новая заявка с сайта

Имя: Мария
Телефон: +7 999 123-45-67
Формат: Детский день рождения
Дата: 12.09.2026
Человек: 8
Комментарий: Имениннице 9 лет, любит кошек

Отправлено 26.08.2026, 17:40
```

Заявка уходит **сразу во все настроенные каналы**, и каждый работает сам по себе:
если почта отвалится, Telegram всё равно дойдёт, и наоборот. А ещё каждая заявка
сохраняется в базу — её видно в админке, даже если оба канала молчат.

### Куда вписывать ключи

**В админку сайта, а не в код.** Зайдите на `/admin.html`, раздел «Заявки с сайта» —
там две карточки, Telegram и Почта. Всё сохраняется в базу на сервере и на
страницах сайта не появляется. Наверху каждой карточки написано текущее
состояние канала.

При сохранении сайт сам проверяет настройки и отправляет проверочное сообщение.
Если бот не может писать в чат или Brevo не принял ключ, вы увидите это сразу,
а не когда потеряете первую заявку.

### Telegram: где взять два значения

**Токен:** напишите [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте
имя. В ответ придёт строка вида `123456789:AAH...`.

**Chat id:** напишите своему боту любое сообщение, потом откройте в браузере
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`.

Чтобы заявки видели несколько человек, заведите группу, добавьте туда бота,
напишите в неё сообщение и возьмите id группы тем же способом — он будет с минусом.

Если токен утёк: @BotFather → `/revoke` → выберите бота. Старый умрёт мгновенно,
новый вставьте в админке.

### Почта: где взять ключ

SMTP не нужен — письмо уходит обычным HTTPS-запросом в Brevo.

1. Зарегистрируйтесь на [brevo.com](https://www.brevo.com/), бесплатный тариф —
   300 писем в день.
2. Подтвердите адрес отправителя в разделе **Senders** (на него придёт письмо
   со ссылкой). Без подтверждения Brevo письма не примет.
3. Создайте ключ в **SMTP & API → API keys**, он начинается на `xkeysib-`.
4. Впишите ключ, подтверждённый адрес отправителя и адрес, куда слать заявки.

Отправитель и получатель — разные вещи: отправитель это «от кого» письмо,
получатель — ваша рабочая почта.

### Архив заявок

Внизу админки — «Последние заявки», сто последних. Видно, кто оставил, когда,
на какую дату, и дошло ли до каждого канала: зелёная метка «доставлено» или
красная «сбой». Заявки со сбоем обведены красным, чтобы их было легко заметить.

Архив живёт в той же базе, что и фотографии, — в `data/`. Это персональные данные
клиентов, так что резервные копии `data/` стоит хранить не менее аккуратно,
чем сам сайт.

### Как поменять список форматов

В `index.html` найдите `<select id="booking-format"` и правьте строки `<option>` —
на сайте появится ровно то, что там написано.

### Защита от спама

- Не больше 5 заявок за 10 минут с одного адреса.
- Скрытое поле-ловушка: боты его заполняют, люди не видят.
- Форма не отправляется в первые 2 секунды после открытия страницы.

## Как устроен сайт

| Файл | Что внутри |
|---|---|
| `index.html` | Вся страница и текст |
| `styles.css` | Оформление сайта |
| `script.js` | Анимации, меню, «оживающая» тарелка |
| `form.js` | Форма заявки |
| `server.py` | Сервер: раздаёт сайт, принимает заявки, хранит фото и настройки |
| `cms.js` | Подставляет заменённые через админку фотографии |
| `admin.html`, `admin.js`, `admin.css` | Админка: фотографии и настройки заявок |
| `login.html`, `login.js`, `login.css` | Вход для персонала |
| `assets/` | Фотографии и логотип |
| `data/` | База: фото, заявки, настройки, пароль. **В гит не попадает**, лежит только на сервере |

### Запустить у себя

```
python3 server.py --port 4173
```

Пароль персонала создастся сам при первом запуске и будет напечатан в консоли,
дальше он лежит в `data/admin-password.txt`.

Настройки можно задать и через переменные окружения — тогда они не хранятся
в базе, а поля в админке только показывают состояние:

```
GUSI_TELEGRAM_TOKEN=... GUSI_TELEGRAM_CHAT_ID=... \
GUSI_BREVO_API_KEY=... GUSI_BREVO_SENDER=... GUSI_BREVO_RECIPIENT=... \
python3 server.py
```

### Важно про обновление

`server.py` — это работающая программа, а не просто файл. После того как
изменения залиты на сервер, **сервис нужно перезапустить**, иначе продолжит
работать старая версия. Правки только в `index.html`, `styles.css` и картинках
перезапуска не требуют.
